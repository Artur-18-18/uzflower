# Галерея изображений товаров с поддержкой свайпов

## ✅ Реализованный функционал

Система поддерживает **множественные изображения товаров** с переключением по свайпу в модальном окне просмотра товара.

---

## 📱 Как это работает

### Клиентская часть (index.html)

При открытии карточки товара:
1. Собираются все изображения: главное (`image_url`) + дополнительные (`images[]`)
2. Инициализируется **Swiper.js** с поддержкой:
   - Свайпов пальцем на мобильных устройствах
   - Стрелок навигации на десктопе
   - Точек пагинации внизу
   - Циклической прокрутки (loop)

### Админ-панель (веб)

1. Откройте панель администратора → Товары → Добавить товар
2. Заполните основную информацию
3. В секции "Дополнительные фотографии":
   - Нажмите на область загрузки
   - Выберите **несколько файлов** сразу (Ctrl+клик или Shift+клик)
   - Или перетащите файлы мышью
4. Сохраните товар

### Админ-бот (Telegram)

1. Нажмите "📦 Добавить товар"
2. Пройдите шаги: название → цена → состав → описание → категория
3. На этапе "📸 Отправьте фотографии товара":
   - Отправьте **до 10 фото** одним сообщением (мультивыбор)
   - Или отправляйте фото по одному
   - Для лучшего качества отправляйте как **"Файл"** (без сжатия)
4. Нажмите "✅ Готово, создаю товар"

## 🗄️ Структура базы данных

### Таблица `products`
- `image_url` - главное изображение товара

### Таблица `product_images`
- `id` - ID изображения
- `product_id` - ID товара (foreign key)
- `url` - URL изображения

---

## 🔌 API Endpoints

### Получить все товары
```
GET /api/products
```
Ответ включает поле `images` - массив дополнительных изображений.

### Добавить изображение к товару
```
POST /api/products/{product_id}/images
Content-Type: application/json

{
  "image_url": "https://..."
}
```

### Загрузить несколько файлов (админ-панель)
```
POST /api/admin/upload-multiple
Content-Type: multipart/form-data

files: [file1, file2, ...]
```
Ответ: `{"urls": ["url1", "url2", ...]}`

### Админ-бот: добавить изображение
```
POST /api/admin/bot/products/{product_id}/images
Authorization: Bearer {api_secret}

{
  "image_url": "https://..."
}
```

## 🛠️ Технические детали

### Swiper.js конфигурация
```javascript
new Swiper('.swiper-container', {
    loop: productImages.length > 1,  // Циклическая прокрутка
    observer: true,                  // Наблюдать за изменениями DOM
    observeParents: true,            // Наблюдать за родительскими элементами
    pagination: {
        el: '.swiper-pagination',
        clickable: true,
    },
    navigation: {
        nextEl: '.swiper-button-next',
        prevEl: '.swiper-button-prev',
    },
});
```

### Обработка изображений
1. Изображения собираются в массив `[main, ...additional]`
2. Удаляются дубликаты по имени файла
3. URL преобразуются в высокое качество (для Cloudinary)
4. Swiper инициализируется после отображения модального окна

## ⚠️ Возможные проблемы

### Изображения не привязаны к товару (product_id = NULL)
**Причина:** Ошибка при создании товара через админ-бота до обновления от 14.03.2026

**Решение:**
```bash
python fix_product_images.py
```

### Свайп не работает
**Причины:**
1. Мало изображений (менее 2) - проверьте `productImages.length`
2. Swiper не инициализирован - проверьте консоль браузера
3. CSS перекрывает свайпы - проверьте `z-index`

**Диагностика:**
- Откройте консоль браузера (F12)
- Ищите сообщения: `🖼️ Product images initialized` и `✅ Swiper initialized`
