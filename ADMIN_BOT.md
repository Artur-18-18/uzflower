# Admin Bot для UzFlower

Админ-бот для управления заказами магазина UzFlower.

## 🤝 Как это работает

```
Покупатель → Бот магазина (@uzflower_bot) → Оформление заказа
                                              ↓
                              Админ-бот (@uzfloweradmin_bot)
                                              ↓
                                    Владелец нажимает кнопки
```

## 📋 Функции

- **Получение уведомлений** о новых заказах
- **Управление заказами** через кнопки:
  - ✅ Принять
  - ❌ Отменить
  - 💬 Написать покупателю
- **Автоматические уведомления** покупателю при изменении статуса

## 🚀 Запуск

### 1. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и настройте:

```bash
# Admin Bot Settings
ADMIN_BOT_TOKEN=8443193754:AAHWu7NqH9nE7UHshZW4Jb0M3TqqMdlRcSA
ADMIN_USER_ID=ваш_telegram_id
TELEGRAM_API_SECRET=telegram-bot-secret-key
```

**Важно:** Укажите ваш `ADMIN_USER_ID`! Для получения ID напишите [@userinfobot](https://t.me/userinfobot).

### 2. Запуск бота

```bash
python run_admin_bot.py
```

Или через Docker (если настроено):

```bash
docker-compose up admin-bot
```

## 🔘 Кнопки управления

### Основные:
- **✅ Принять** — статус `accepted`, покупатель получает уведомление
- **❌ Отменить** — статус `cancelled`, покупатель уведомлён об отмене
- **💬 Написать покупателю** — открывается чат с покупателем

### Дополнительные:
- **📋 Детали заказа** — показывает полную информацию о заказе
- **🚚 В доставке** — статус `delivering`, заказ передан курьеру
- **✔️ Завершён** — статус `completed`, заказ выполнен

## 🛠️ API Endpoints

### Отправка заказа в админ-бот
```
POST /api/orders (автоматически при создании заказа)
```

### Обновление статуса из админ-бота
```
PATCH /api/admin/orders/{order_id}/status
Body: {
    "status": "accepted" | "cancelled",
    "admin_id": 123456789,
    "api_secret": "telegram-bot-secret-key"
}
```

## 📁 Структура файлов

```
app/admin_bot/
├── __init__.py    # Инициализация пакета
├── bot.py         # Создание бота и диспетчера
├── config.py      # Конфигурация и настройки
├── handlers.py    # Обработчики команд и callback

```

## 🔧 Команды бота

- `/start` - Главное меню
- `/help` - Справка
- `/orders` - Последние заказы (в разработке)
- `/settings` - Настройки

## 🐛 Отладка

Логи сохраняются в файл `admin_bot.log`.

Для включения подробного логирования измените уровень в `run_admin_bot.py`:

```python
logging.basicConfig(
    level=logging.DEBUG,  # Было: logging.INFO
    ...
)
```

## 📝 Примечания

- Бот работает в режиме polling
- Для продакшена рекомендуется использовать webhook
- Убедитесь, что `TELEGRAM_API_SECRET` совпадает в `.env` и `main.py`
