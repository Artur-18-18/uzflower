# 🚚 Доставка и Оплата в UzFlower Bot

## Обзор изменений

Добавлен полный цикл оформления заказа с:
- **Опциональной доставкой** (доставка или самовывоз)
- **Оплатой по номеру карты**
- **Загрузкой скриншота чека**
- **Уведомлением админа** в админ-боте
- **Подтверждением заказа** админом

---

## 📋 Изменения в базе данных

### Новые поля в таблице `orders`:

| Поле | Тип | Описание |
|------|-----|----------|
| `delivery_option` | BOOLEAN | True = доставка, False = самовывоз |
| `delivery_price` | FLOAT | Стоимость доставки (по умолчанию 0) |
| `payment_proof_url` | TEXT | URL скриншота чека |
| `payment_proof_file_id` | TEXT | Telegram file_id скриншота |
| `card_number` | TEXT | Номер карты для оплаты (копия на момент заказа) |
| `delivery_address` | TEXT | Теперь необязательно (NULL для самовывоза) |
| `payment_status` | TEXT | waiting, paid, error |

---

## 🤖 Telegram Bot (основной)

### Новый поток оформления заказа:

1. **Шаг 1/7** - Ввод имени
2. **Шаг 2/7** - Ввод телефона
3. **Шаг 3/7** - Выбор доставки/самовывоза
4. **Шаг 4/7** - Ввод адреса (если доставка) ИЛИ выбор даты/времени
5. **Шаг 5/7** - Выбор даты/времени доставки
6. **Шаг 6/7** - Оплата (показ номера карты + загрузка скриншота чека)
7. **Финал** - Подтверждение заказа

### Новые FSM состояния:

```python
class OrderState(StatesGroup):
    waiting_for_name = State()
    waiting_for_phone = State()
    waiting_for_delivery = State()      # Выбор доставки/самовывоза
    waiting_for_address = State()       # Адрес доставки
    waiting_for_datetime = State()      # Дата и время
    waiting_for_payment_proof = State() # Загрузка скриншота чека
    waiting_for_comment = State()       # Комментарий
```

### Клавиатуры:

- `create_delivery_keyboard()` - Выбор доставки/самовывоза
- `create_datetime_keyboard()` - Выбор даты/времени
- `create_back_cancel_keyboard()` - Навигация (Назад/Отмена)

## 💳 Оплата

### Номер карты

- Хранится в настройках админ-бота (`admin_bot_settings["card_number"]`)
- Настраивается через админ-бота: кнопка "💳 Изменить номер карты"
- Показывается клиенту на этапе оплаты
- Сохраняется в заказе на случай изменения

### Скриншот чека

1. Клиент отправляет скриншот чека после оплаты
2. Бот загружает скриншот на сервер (`/api/telegram/orders/{order_id}/payment-proof`)
3. URL скриншота сохраняется в заказе
4. Скриншот отправляется админу в уведомление

## 🛠 API Endpoints

### Для Telegram бота:

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/telegram/card-number` | GET | Получить номер карты |
| `/api/telegram/orders/create` | POST | Создать заказ |
| `/api/telegram/orders/{order_id}/payment-proof` | POST | Загрузить скриншот чека |
| `/api/telegram/orders/{order_id}/payment` | PUT | Обновить оплату |
| `/api/telegram/orders/notify-admin` | POST | Уведомить админа о заказе |

### Для Админ бота:

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/admin/bot/orders/{order_id}` | GET | Получить заказ (с новыми полями) |
| `/api/admin/bot/settings/card` | GET/POST | Номер карты |
| `/api/admin/bot/settings/message` | GET/POST | Сообщение покупателю |

## 📱 Админ бот

### Обновлённые функции:

1. **Просмотр заказа** (`details_{order_id}`):
   - Показывает тип доставки (🚚 Доставка / 🏃 Самовывоз)
   - Показывает статус оплаты (✅ Оплачен / ⏳ Ожидает)
   - Показывает номер карты
   - Показывает информацию о чеке
   - Отправляет скриншот чека (если есть)

2. **Принятие заказа** (`accept_{order_id}`):
   - Статус меняется на "accepted"

3. **Отмена заказа** (`cancel_{order_id}`):
   - Статус меняется на "cancelled"

## 🎯 Стоимость доставки

По умолчанию установлена стоимость **50,000 сум** за доставку.

Изменить можно в `app/telegram_bot/handlers.py`:
```python
delivery_price = 50000 if delivery_option else 0
```

## 🧪 Тестирование

### Проверка полного цикла:

1. Запустите основной бот: `python run_bot.py`
2. Запустите админ-бот: `python run_admin_bot.py`
3. Запустите сервер: `python main.py`
4. Оформите заказ через Telegram:
   - Введите имя
   - Введите телефон
   - Выберите доставку
   - Введите адрес
   - Выберите дату/время
   - Оплатите по номеру карты
   - Отправьте скриншот чека
5. Проверьте уведомление в админ-боте
6. Нажмите "✅ Принять" или "📋 Детали"
