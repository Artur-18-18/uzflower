## 🎯 Возможности

### Главное меню
```
📦 Добавить товар      ✏️ Редактировать товар
💳 Изменить номер карты  💬 Сообщение покупателю
📋 Список товаров       ❌ Удалить товар
📊 Статистика          📦 Заказы
📢 Рассылка
```

### Функции

| Функция | Описание |
|---------|----------|
| 📦 Добавить товар | Пошаговое добавление товара (название → цена → описание → категория → фото) |
| ✏️ Редактировать товар | Изменение существующих товаров |
| 💳 Изменить номер карты | Обновление номера карты для оплаты |
| 💬 Сообщение покупателю | Настройка авто-сообщения после заказа |
| 📋 Список товаров | Просмотр всех товаров в каталоге |
| ❌ Удалить товар | Удаление товара из каталога |
| 📊 Статистика | Просмотр статистики магазина |
| 📦 Заказы | Просмотр последних заказов |
| 📢 Рассылка | Отправка сообщений всем пользователям |

### Управление заказами

При поступлении нового заказа администратор получает уведомление с кнопками:
- ✅ Принять
- ❌ Отменить
- 💬 Написать покупателю
- 📋 Детали заказа
- 🚚 В доставке
- ✔️ Завершён

## 🔧 Установка

### 1. Создайте бота в @BotFather

1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Введите имя бота (например: `UzFlower Admin`)
4. Введите username бота (например: `uzfloweradmin_bot`)
5. Сохраните полученный токен

### 2. Узнайте свой Telegram ID

1. Откройте @userinfobot
2. Нажмите `/start`
3. Скопируйте свой ID (например: `1186442364`)

### 3. Настройте переменные окружения

Отредактируйте файл `.env`:

```env
# Токен админ-бота
ADMIN_BOT_TOKEN=8443193754:AAHWu7NqH9nE7UHshZW4Jb0M3TqqMdlRcSA

# Ваш Telegram ID
ADMIN_USER_ID=1186442364

# Список администраторов (через запятую)
ADMIN_IDS=1186442364,123456789,987654321

# URL API сайта
TELEGRAM_API_URL=http://localhost:8000

# Секретный ключ API
TELEGRAM_API_SECRET=telegram-bot-secret-key
```

## 📖 Использование

### Первый запуск

1. Найдите вашего бота в Telegram (например: @uzfloweradmin_bot)
2. Нажмите `/start`
3. Если ваш ID указан в `ADMIN_IDS`, вы увидите главное меню

### Добавление товара

1. Нажмите кнопку **📦 Добавить товар**
2. Введите название товара (например: `Букет "Red Love"`)
3. Введите цену (например: `180000`)
4. Введите описание товара
5. Выберите категорию из предложенных
6. Отправьте фотографию товара
7. Товар будет добавлен в каталог

### Изменение номера карты

1. Нажмите кнопку **💳 Изменить номер карты**
2. Введите новый номер карты (16 цифр)
3. Номер будет сохранён и отображаться покупателям при оплате

### Настройка сообщения покупателю

1. Нажмите кнопку **💬 Сообщение покупателю**
2. Введите текст сообщения
3. Покупатели будут видеть это сообщение после оформления заказа

### Просмотр статистики

1. Нажмите кнопку **📊 Статистика** или команду `/stats`
2. Вы увидите:
   - Количество товаров
   - Заказы сегодня
   - Доход сегодня
   - Количество пользователей
   - Статистику за всё время

### Просмотр заказов

1. Нажмите кнопку **📦 Заказы** или команду `/orders`
2. Вы увидите последние 10 заказов

### Рассылка сообщений

1. Нажмите кнопку **📢 Рассылка**
2. Введите текст сообщения
3. Сообщение будет отправлено всем пользователям

## 🔒 Безопасность

### Ограничение доступа

Бот проверяет Telegram ID каждого пользователя:

```python
def is_admin(user_id: int) -> bool:
    return user_id in settings.admin_ids
```

Если пользователь не в списке администраторов:
- Сообщения игнорируются
- Команды не выполняются
- Кнопки не работают

### Список администраторов

В файле `.env`:

```env
# Один администратор
ADMIN_IDS=1186442364

# Несколько администраторов
ADMIN_IDS=1186442364,123456789,987654321
```

### Логи доступа

Все попытки несанкционированного доступа логируются:

```
⚠️ Попытка доступа от неавторизованного пользователя: 999888777
```

## 🛠 API методы

Бот использует следующие API эндпоинты:

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/api/products` | Получить список товаров |
| `POST` | `/api/products` | Создать товар |
| `DELETE` | `/api/products/{id}` | Удалить товар |
| `GET` | `/api/admin/stats` | Получить статистику |
| `GET` | `/api/admin/orders` | Получить заказы |
| `PATCH` | `/api/admin/orders/{id}/status` | Обновить статус заказа |
| `POST` | `/api/admin/broadcast` | Отправить рассылку |

## ⚠️ Важные замечания

1. **Фотографии товаров**: При добавлении товара через бота фото необходимо загрузить отдельно через админ-панель сайта (в текущей версии).

2. **Номер карты**: В текущей версии номер карты сохраняется только в памяти. Для постоянного хранения необходимо добавить эндпоинт в API.

3. **Рассылка**: Массовая рассылка может занять время при большом количестве пользователей.
