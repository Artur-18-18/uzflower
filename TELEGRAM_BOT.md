# 🌸 Telegram Bot для UzFlower

## Общая схема работы

```
Ты (админ)
   ↓
Публикуешь пост в Telegram канале
   ↓
Telegram Bot получает сообщение
   ↓
Бот отправляет данные в API сайта
   ↓
Товар автоматически появляется на сайте
```

## Заказ через Telegram

```
Пользователь на сайте
   ↓
Нажал "Заказать в Telegram"
   ↓
Открывается бот с этим букетом
   ↓
Пользователь пишет заказ
   ↓
Сообщение приходит владельцу
```

## 📋 Настройка

### 1. Создать Telegram канал

Например: `@uzflower_shop`

В канал публикуешь:
- Фото букета
- Название
- Цена
- Описание

### 2. Создать бота через @BotFather

Бот уже создан: **@uzflowershop_bot**

Токен бота сохранён в `.env` файле.

### 3. Добавить бота администратором в канал

1. Открой настройки канала
2. Добавь администратора
3. Найди бота по username (`@uzflower_bot`)
4. Дай права на чтение сообщений

### 4. Настроить переменные окружения

Создай файл `.env` (скопируй из `.env.example`):

```bash
# Telegram Bot Settings
TELEGRAM_BOT_TOKEN=8676150074:AAFXKPfATw1cPrJVxiV4OP4vbmgdlHaEKN0
TELEGRAM_CHANNEL_ID=@uzflower_shop
TELEGRAM_OWNER_ID=123456789
TELEGRAM_API_URL=http://localhost:8000
TELEGRAM_API_SECRET=telegram-bot-secret-key

# Database
DATABASE_URL=sqlite:///./uzflower.db
```

**Важно:**
- `TELEGRAM_CHANNEL_ID` - ID канала (можно узнать через @userinfobot)
- `TELEGRAM_OWNER_ID` - Твой ID для уведомлений (можно узнать через @userinfobot)
- `TELEGRAM_API_SECRET` - должен совпадать с `TELEGRAM_BOT_SECRET_KEY` в main.py

### 5. Установить зависимости

```bash
pip install -r requirements.txt
```

## 🚀 Запуск

### Запуск сайта (FastAPI)

```bash
python main.py
```

Сайт будет доступен по адресу: `http://localhost:8000`

### Запуск бота (отдельный процесс)

```bash
python -m app.telegram_bot.bot
```

Или создай файл `run_bot.py`:

```python
import asyncio
from app.telegram_bot import start_bot

asyncio.run(start_bot())
```

И запусти:

```bash
python run_bot.py
```

## 🛒 Как работает заказ

1. Пользователь на сайте нажимает **"Заказать в Telegram"**
2. Открывается бот с ссылкой: `https://t.me/uzflowershop_bot?start=product_12`
3. Бот показывает товар:
   ```
   🌸 Вы хотите заказать:
   
   Красные розы Premium
   
   💰 Цена: 250,000 сум
   
   📝 Описание:
   Прекрасный букет из 25 красных роз...
   ```
4. Пользователь нажимает **"🛒 Оформить заказ"**
5. Бот спрашивает:
   - 👤 Имя
   - 📱 Номер телефона
   - 💬 Комментарий (можно пропустить)
6. Бот создаёт заказ и отправляет уведомление владельцу

## 🔧 API Endpoints

### Для бота (защищены секретным ключом):

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/telegram/products` | POST | Создать товар из Telegram |
| `/api/telegram/orders/create` | POST | Создать заказ из бота |
| `/api/telegram/orders` | POST | Уведомление о заказе |
| `/api/products/{id}` | GET | Получить товар по ID |

## 🐛 Отладка

### Бот не реагирует на посты в канале

1. Проверь, что бот добавлен администратором в канал
2. Проверь `TELEGRAM_CHANNEL_ID` в `.env`
3. Включи логирование, смотри `server_debug.log`

### Ошибка "Invalid authorization"

Проверь, что `TELEGRAM_API_SECRET` в `.env` совпадает с `TELEGRAM_BOT_SECRET_KEY` в `main.py`

### Товар не создаётся

1. Проверь логи бота
2. Проверь, что API сайта доступен
3. Проверь формат поста (название + цена)
