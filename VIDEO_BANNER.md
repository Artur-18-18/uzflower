# 🎬 Видео-баннер для главной страницы

## Описание

В боковой панели фильтров на главной странице отображается видео-баннер вертикального формата (9:16).

## Расположение

Видео находится под фильтрами (сортировка, категория, цена).

## Технические требования

### Формат видео:
- **Соотношение сторон:** 9:16 (вертикальное, как для телефона)
- **Формат:** MP4 (H.264 codec)
- **Размер:** до 5 MB
- **Длительность:** 10-30 секунд
- **Звук:** не требуется (видео без звука, `muted`)

### Файлы:

1. **Видео:** `static/uploads/banners/promo-video.mp4`
2. **Постер (превью):** `static/uploads/banners/video-poster.jpg`

## Как добавить видео

### Шаг 1: Подготовьте видео

1. Создайте вертикальное видео 9:16
2. Экспортируйте в MP4 (H.264)
3. Оптимизируйте размер (до 5 MB)

### Шаг 2: Загрузите на сервер

```bash
# Скопируйте видео в директорию баннеров
cp promo-video.mp4 c:\Users\matka\uzflower\static\uploads\banners\

# Создайте постер (кадр из видео)
ffmpeg -i promo-video.mp4 -ss 00:00:01 -vframes 1 video-poster.jpg
```

### Шаг 3: Проверьте

1. Откройте главную страницу
2. Прокрутите до секции "Наши букеты"
3. Видео должно автоматически воспроизводиться в боковой панели

## Настройки воспроизведения

Видео настроено на:
- ✅ Автоматическое воспроизведение (`autoplay`)
- ✅ Зацикливание (`loop`)
- ✅ Без звука (`muted`)
- ✅ Оптимизация для мобильных (`playsinline`)

## Изменение текста

Текст под видео находится в `templates/index.html`:

```html
<p class="text-xs text-gray-600 mt-3 text-center italic">
    🌸 Красота в каждом букете
</p>
```

## Отключение видео

Если видео не нужно, закомментируйте блок:

```html
<!--
<div class="bg-rose-50 rounded-xl p-4 shadow-sm">
    <video>...</video>
</div>
-->
```

## Примеры использования

### Сезонная реклама:
- 8 Марта — видео с красными тюльпанами
- День влюблённых — видео с красными розами
- Свадьбы — видео с белыми букетами

### Акции:
- Скидка 20% — видео с текстом акции
- Новый товар — видео новинки

## Рекомендации

1. **Используйте лёгкое видео** — быстрая загрузка
2. **Яркий первый кадр** — привлекает внимание
3. **Короткий цикл** — 10-15 секунд достаточно
4. **Без текста на видео** — текст может не читаться
