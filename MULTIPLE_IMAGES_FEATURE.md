# Множественные изображения товаров

## Обзор изменений

Реализована поддержка загрузки **нескольких фотографий** для одного товара одновременно в:
- ✅ Админ-боте (Telegram)
- ✅ Админ-панели (веб-интерфейс)
- ✅ На сайте (просмотр с пролистыванием)

---

## 📋 Изменения в базе данных

Используется существующая таблица `product_images`:
```sql
CREATE TABLE product_images (
    id INTEGER PRIMARY KEY,
    product_id INTEGER REFERENCES products(id),
    url TEXT
)
```

---

## 🔧 Backend изменения (main.py)

### Новые API эндпоинты:

#### 1. Загрузка нескольких файлов (админ-панель)
```python
POST /api/admin/upload-multiple
```
**Параметры:**
- `files` - список файлов (multipart/form-data)

**Ответ:**
```json
{
  "urls": ["https://...", "https://...", ...]
}
```

#### 2. Добавление изображения к товару
```python
POST /api/products/{product_id}/images
```
**Тело запроса:**
```json
{
  "image_url": "https://..."
}
```

#### 3. Удаление изображения товара
```python
DELETE /api/products/{product_id}/images/{image_id}
```

#### 4. Эндпоинт для админ-бота
```python
POST /api/admin/bot/products/{product_id}/images
```

### Обновлённые эндпоинты:

Все эндпоинты получения товаров теперь возвращают поле `images`:
- `GET /api/products` - список товаров
- `GET /api/products/{product_id}` - товар по ID
- `GET /api/admin/products` - для админки
- `GET /api/admin/bot/products` - для админ-бота

**Пример ответа:**
```json
{
  "id": 1,
  "name": "Букет",
  "image_url": "https://... (главное фото)",
  "images": [
    "https://... (доп. фото 1)",
    "https://... (доп. фото 2)"
  ],
  ...
}
```

## 🤖 Админ-бот (Telegram)

### Файлы:
- `app/admin_bot/handlers.py`
- `app/admin_bot/services.py`

### Изменения:

#### 1. Загрузка нескольких фото
Теперь при добавлении товара:
1. Админ отправляет **от 1 до 10 фото**
2. Бот сохраняет каждое фото во временное хранилище
3. После нажатия кнопки "**✅ Готово, создаю товар**":
   - Первое фото становится **главным** (`image_url`)
   - Остальные сохраняются в таблицу `product_images`

#### 2. Новый метод в services.py
```python
async def add_product_image(self, product_id: int, image_url: str) -> bool
```

### Сценарий использования:
```
1. /start → 📦 Добавить товар
2. Вводим название → цену → описание
3. Выбираем категорию
4. Отправляем 1-10 фото (можно пачкой)
5. Нажимаем "✅ Готово, создаю товар"
6. Товар создан с фото!
```

## 🌐 Сайт (клиентская часть)

### Файл:
- `templates/index.html`
- `static/js/app.js`

### Изменения в модальном окне товара:

#### 1. HTML структура
Добавлены:
- Кнопки "влево" / "вправо" для переключения
- Индикаторы (точки) внизу
- Контейнер для карусели

```html
<div class="relative">
  <button onclick="prevImage()">←</button>
  <button onclick="nextImage()">→</button>
  <img id="detail-image" src="..." />
  <div id="image-indicators"></div>
</div>
```

#### 2. JavaScript функции:
- `openProductDetail(product)` - обновлена для сбора всех фото
- `updateProductImage()` - установка текущего фото
- `updateImageIndicators()` - отрисовка точек
- `updateNavigationButtons()` - показать/скрыть кнопки
- `nextImage()` / `prevImage()` - переключение
- `goToImage(index)` - переход к фото по индексу
- `handleTouchStart/Move/End()` - поддержка свайпов
- `closeProductDetail()` - сброс переменных

### Функционал:
- ✅ Стрелки влево/вправо (показываются при >1 фото)
- ✅ Индикаторы-точки (активная подсвечена)
- ✅ Свайпы на мобильных устройствах
- ✅ Круговая прокрутка (после последнего - первый)
- ✅ Клик по точке - переход к фото

### Сценарий использования:
```
1. Клиент открывает карточку товара
2. Если фото несколько:
   - Видит стрелки ← →
   - Видит точки внизу
   - Может свайпнуть на мобильном
3. Листает фото, выбирает размер, заказывает
```

---

## 📝 Заметки

1. **Главное фото** - всегда `image_url` товара
2. **Дополнительные фото** - массив `images` из таблицы `product_images`
3. **Максимум фото** - рекомендуется до 10 штук
4. **Порядок фото** - сохраняется в порядке добавления
5. **При удалении товара** - все связанные фото удаляются (CASCADE)
