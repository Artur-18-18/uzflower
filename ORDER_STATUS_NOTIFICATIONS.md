# 🔔 Уведомления покупателям о статусе заказа

## Описание

При принятии или отмене заказа администратором, покупатель автоматически получает уведомление в Telegram.

## Как это работает

### 1. Администратор нажимает кнопку в админ-боте

- **"✅ Принять"** — заказ принимается
- **"❌ Отклонить"** — заказ отменяется

### 2. Система отправляет уведомление покупателю

Покупатель получает сообщение в Telegram от основного бота (@uzflowershop_bot).

## Тексты уведомлений

### ✅ Заказ принят

```
✅ Ваш заказ принят!

Уважаемый(ая) [Имя],

Ваш заказ #[order_id] был принят нашим менеджером.

📦 Мы уже начали подготовку вашего заказа.
🚚 В ближайшее время с вами свяжутся для уточнения деталей доставки.

Спасибо за ваш заказ! 💐
```

### ❌ Заказ отменён

```
❌ Ваш заказ отменён

Уважаемый(ая) [Имя],

К сожалению, ваш заказ #[order_id] был отменён.

По вопросам обращайтесь в службу поддержки.

Приносим извинения за неудобства.
```

## Технические детали

### Последовательность действий

1. Админ нажимает кнопку "Принять" или "Отклонить"
2. Админ-бот получает callback query
3. Получает информацию о заказе из API
4. Находит Telegram ID покупателя
5. Обновляет статус заказа в БД
6. Отправляет запрос на `/api/admin/notify-customer-order-status`
7. Основной бот отправляет сообщение покупателю
8. Уведомление сохраняется в таблицу `support_messages`

### API эндпоинты

**`POST /api/admin/notify-customer-order-status`**

Отправляет уведомление покупателю.

**Параметры:**
```json
{
  "order_id": 123,
  "status": "accepted",  // или "cancelled"
  "customer_telegram_id": 1186442364,
  "customer_name": "Иван"
}
```

**Ответ:**
```json
{
  "status": "ok",
  "message_id": 456
}
```

### Методы сервиса

**`notify_customer_order_status()`** в `app/admin_bot/services.py`

```python
await api.notify_customer_order_status(
    order_id=123,
    status="accepted",
    customer_telegram_id=1186442364,
    customer_name="Иван"
)
```

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Покупатель не найден в БД | Уведомление не отправляется, статус обновляется |
| Покупатель заблокировал бота | Ошибка Telegram, логирование в сервере |
| TELEGRAM_BOT_TOKEN не настроен | Ошибка 500, логирование |

## Примеры использования

### Сценарий 1: Успешное принятие заказа

1. Админ получает уведомление о новом заказе #123
2. Админ нажимает "✅ Принять"
3. Покупатель получает: "✅ Ваш заказ принят!"
4. Статус заказа меняется на `accepted`

### Сценарий 2: Отмена заказа

1. Админ получает уведомление о новом заказе #124
2. Админ нажимает "❌ Отклонить"
3. Покупатель получает: "❌ Ваш заказ отменён"
4. Статус заказа меняется на `cancelled`

### Сценарий 3: Покупатель без Telegram ID

1. Админ нажимает "✅ Принять"
2. Система не находит Telegram ID покупателя
3. Статус обновляется, но уведомление не отправляется
4. В логе: предупреждение об отсутствии Telegram ID
