# 🔧 Исправление ботов UzFlower

## ✅ Что было исправлено

### 1. Админ-бот: Загрузка изображений
**Проблема:** `❌ Не удалось загрузить ни одно фото! Проверите подключение к серверу.`

**Причина:** 
- Эндпоинт `/api/admin/bot/upload` использовал `Form(...)` для `api_secret`
- Бот отправлял `api_secret` в `data`, но это не работало корректно

**Решение:**
- Изменили эндпоинт на использование `Header(...)` для авторизации
- Обновили `services.py` для отправки `Authorization: Bearer {api_secret}`
- Увеличили таймаут с 30 до 60 секунд
- Добавлена поддержка обоих форматов авторизации

### 2. Основной бот: Получение товаров с сайта
**Проблема:** Бот не видит товары с сайта

**Причина:**
- Боты используют `TELEGRAM_API_URL=http://localhost:8000`
- На Render.com это работает (боты в том же контейнере)
- Локально нужно запускать сервер перед ботом

**Решение:**
- Добавлено подробное логирование API запросов
- Увеличен таймаут до 60 секунд
- Проверка переменных окружения

## 🚀 Как использовать админ-бота

### Добавление товара

1. **Запустите админ-бота:**
   ```
   /start
   ```

2. **Нажмите "📦 Добавить товар"**

3. **Введите данные:**
   - Название товара
   - Цену (только число, например: `550000`)
   - Описание
   - Состав
   - Категорию (выберите из списка)

4. **Отправьте фото:**
   - Отправьте фото как изображение (не файл!)
   - Можно отправить до 10 фото
   - После каждого фото бот подтвердит загрузку
   - Когда закончите, нажмите **"✅ Готово, создаю товар"**

5. **Готово!** Товар создан и отображается на сайте

## 🛠 Отладка

### Админ-бот не загружает фото?

#### 1. Проверьте логи сервера

Ищите сообщения:
```
📤 Загрузка фото на сервер: telegram_...
📥 Ответ сервера: статус=200
✅ Фото загружено: https://...
```

#### 2. Проверьте переменные окружения

```bash
# В .env или Render Environment Variables
TELEGRAM_API_SECRET=telegram-bot-secret-key
```

#### 3. Проверьте API вручную

```bash
# Проверьте что сервер работает
curl http://localhost:8000/api/products

# Проверьте создание товара
curl -X POST http://localhost:8000/api/admin/bot/products \
  -H "Authorization: Bearer telegram-bot-secret-key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Тест","price":100,"description":"Тест","category_slug":"bouquets"}'
```

### Основной бот не видит товары?

#### 1. Проверьте что сервер запущен

```bash
# Запустите сервер
python main.py

# Проверьте API
curl http://localhost:8000/api/products/2
```

#### 2. Проверьте логи бота

Ищите:
```
🔍 Запрос товара #2: GET http://localhost:8000/api/products/2
📥 Ответ API: статус=200
✅ Товар #2 получен успешно: Roza
```

#### 3. Проверьте TELEGRAM_API_URL

```bash
# В .env должно быть:
TELEGRAM_API_URL=http://localhost:8000

# На Render.com оставьте localhost!
# Боты работают в том же контейнере
```

## 🆘 Если что-то не работает

### 1. Перезапустите сервер

```bash
# Остановите все процессы Python
taskkill /F /IM python.exe

# Запустите сервер
python main.py

# В другом окне запустите ботов
python run_bot.py
python run_admin_bot.py
```

### 2. Проверьте .env

```bash
# Убедитесь что .env существует
cat .env

# Проверьте TELEGRAM_API_SECRET
# Должно быть: telegram-bot-secret-key
```

### 3. Очистите кэш Telegram

Иногда Telegram кэширует старые сообщения бота. Просто подождите несколько минут.

### 4. Проверьте токены ботов

Убедитесь, что токены правильные:
- `@BotFather` → проверьте токены
- Обновите в `.env` и на Render
