# 🎬 Боковой баннер - Управление через админ-панель

## Описание

Боковой баннер отображается в левой панели на главной странице сайта (под фильтрами) и может показывать вертикальное видео 9:16.

## Расположение на сайте

```
Главная страница → Наши букеты → Левая панель → Под фильтрами
```

## Настройка в админ-панели

### Шаг 1: Откройте админ-панель

1. Войдите в админ-панель (`/admin`)
2. Перейдите на вкладку **"Баннеры"**

### Шаг 2: Настройте боковой баннер

В верхней части вкладки "Баннеры" находится секция **"Боковой баннер"**:

```
┌─────────────────────────────────────────┐
│ 📱 Боковой баннер                       │
├─────────────────────────────────────────┤
│ URL видео:                              │
│ [ /static/uploads/banners/video.mp4 ]  │
│                                         │
│ Текст под видео:                        │
│ [ 🌸 Красота в каждом букете       ]   │
│                                         │
│ [💾 Сохранить] [🔄 Обновить]            │
└─────────────────────────────────────────┘
```

### Шаг 3: Заполните поля

1. **URL видео** - путь к видеофайлу:
   - Пример: `/static/uploads/banners/promo-video.mp4`
   - Формат: MP4 (H.264)
   - Соотношение: 9:16 (вертикальное)
   - Размер: до 5 MB

2. **Текст под видео** - подпись под баннером:
   - Пример: `🌸 Красота в каждом букете`
   - Длина: до 50 символов

### Шаг 4: Сохраните

Нажмите кнопку **"💾 Сохранить"**

## API эндпоинты

### Получить настройки

```http
GET /api/admin/bot/settings/sidebar-banner
Authorization: Bearer {TELEGRAM_API_SECRET}
```

**Ответ:**
```json
{
  "video_url": "/static/uploads/banners/promo-video.mp4",
  "text": "🌸 Красота в каждом букете"
}
```

### Сохранить настройки

```http
POST /api/admin/bot/settings/sidebar-banner
Authorization: Bearer {TELEGRAM_API_SECRET}
Content-Type: application/json

{
  "video_url": "/static/uploads/banners/promo-video.mp4",
  "text": "🌸 Красота в каждом букете"
}
```

**Ответ:**
```json
{
  "status": "ok",
  "video_url": "/static/uploads/banners/promo-video.mp4",
  "text": "🌸 Красота в каждом букете"
}
```

## Как это работает

### На стороне сервера:

1. Настройки хранятся в `admin_bot_settings` (в памяти)
2. При загрузке главной страницы JavaScript запрашивает настройки
3. Если видео есть - отображается видео
4. Если видео нет - отображается красивая заглушка

### На стороне клиента:

```javascript
// Загрузка баннера при загрузке страницы
document.addEventListener('DOMContentLoaded', loadSidebarBanner);

async function loadSidebarBanner() {
    const response = await fetch('/api/admin/bot/settings/sidebar-banner');
    const data = await response.json();
    
    if (data.video_url) {
        // Отображаем видео
        container.innerHTML = `<video src="${data.video_url}" ...>`;
    } else {
        // Отображаем заглушку
        container.innerHTML = `<div class="bg-gradient...">🌸</div>`;
    }
}
```

## Форматы видео

### Рекомендуемые параметры:

| Параметр | Значение |
|----------|----------|
| Соотношение сторон | 9:16 (вертикальное) |
| Разрешение | 1080x1920 или 720x1280 |
| Формат | MP4 (H.264) |
| Размер | до 5 MB |
| Длительность | 10-30 секунд |
| Звук | не требуется (muted) |

### Примеры использования:

1. **Сезонная реклама:**
   - 8 Марта - красные тюльпаны
   - День влюблённых - красные розы

2. **Акции:**
   - Скидка 20% на все букеты
   - Бесплатная доставка

3. **Новинки:**
   - Новая коллекция
   - Эксклюзивные букеты

## Загрузка видео на сервер

### Способ 1: Через файловый менеджер

1. Подключитесь к серверу по FTP/SFTP
2. Загрузите видео в папку:
   ```
   /static/uploads/banners/
   ```
3. Скопируйте URL видео

### Способ 2: Через админ-панель (если есть загрузчик)

1. Админ-панель → Баннеры
2. Добавить файл
3. Выберите видео
4. Скопируйте URL

### Способ 3: Через командную строку

```bash
# Скопируйте видео на сервер
scp promo-video.mp4 user@server:/path/to/static/uploads/banners/
```

```

```

### 2. Прокрутите до секции "Наши букеты"

- ✅ Текст должен отображаться под видео

## Устранение неполадок

### Ошибка: "Failed to load resource: 404"

**Причина:** Видеофайл не найден

**Решение:**
1. Проверьте путь к видео
2. Убедитесь, что файл существует на сервере
3. Проверьте права доступа к файлу

### Ошибка: "Video cannot be played"

**Причина:** Неподдерживаемый формат видео

**Решение:**
1. Конвертируйте видео в MP4 (H.264)
2. Используйте онлайн-конвертеры или FFmpeg:
   ```bash
   ffmpeg -i input.mov -c:v libx264 -preset slow -crf 22 output.mp4
   ```

### Баннер не отображается

**Причина:** JavaScript ошибка

**Решение:**
1. Откройте консоль браузера (F12)
2. Найдите ошибку
3. Проверьте, что `loadSidebarBanner()` вызывается

## Отключение баннера

Чтобы временно отключить баннер:

1. Админ-панель → Баннеры
2. Очистите поле "URL видео"
3. Нажмите "Сохранить"

На сайте отобразится красивая заглушка с текстом.
